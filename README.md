# Physics of Cybersecurity: Electromagnetic Spectrum Applications

This site is an incubator for the conversation on the role of physics in cybersecurity.

The materials are being developed to replicate a college class which includes hands-on activities.

The initial skeleton of topics and materials were generated using AI technologies on February 1 and 2, 2025.
